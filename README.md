🎮 Win Streak Counter — Dead by Daylight

Um contador de Win Streak desenvolvido para jogadores de Dead by Daylight, permitindo acompanhar de forma simples e prática a sequência de vitórias durante as partidas.

📌 Sobre o projeto

O Win Streak Counter DBD é uma aplicação desenvolvida em C#/.NET com o objetivo de facilitar o acompanhamento de sequências de vitórias no Dead by Daylight.

O programa permite registrar suas vitórias e derrotas e manter o controle da sua sequência atual, tornando mais fácil acompanhar seu desempenho durante uma sessão de jogo.

✨ Funcionalidades

🏆 Contador de vitórias consecutivas

❌ Registro de derrota e reinício da sequência

📊 Acompanhamento da Win Streak atual

🖥️ Interface simples e leve

🎮 Desenvolvido especificamente para Dead by Daylight

💾 Aplicação desktop independente

🎯 Objetivo

O projeto foi criado para ser uma ferramenta pequena e prática para jogadores que gostam de acompanhar suas Win Streaks no Dead by Daylight, sem precisar utilizar planilhas ou realizar a contagem manualmente.
